Limits and follow-ups

- This is selective adoption on top of Robin's work, not a merge of the proposal
  branch or implementation of all 22 requests. No ontology/schema constraints
  were relaxed. Package identities, extra affiliations and raw Project require
  coordinated upstream changes; other compatible ideas remain in adoption.txt.
- Existing reconciled email can come from context or GitHub and still lacks
  source-aware profile routing. It was not changed or newly exposed here.
- Bare website domains and Twitter handles remain internal facts; a future
  explicit normalization rule can promote them once semantics are agreed.
- Restart after deployment: mapping versions/fingerprints change cache keys.
  The private graph adds an in-memory copy per extraction; it is never persisted
  as a public artifact. Existing substrate writes remain opt-in.
- Validation was offline. No live providers, services, indices or stored graphs
  were modified or benchmarked by this addition.
