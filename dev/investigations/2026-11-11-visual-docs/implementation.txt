Accuracy decisions grounded in source
  - API /v2 remains distinct from generated v3.0.0-develop ontology output.
  - Generation uses PLAN_BY_TYPE in pipeline/orchestrator.py; post-agent chains
    live in pipeline/run.py and are orchestrated by services/extraction.py.
  - Rule-based is LLM-free. Hybrid uses typed refiners and enabled affiliation
    resolution, not the obsolete three-field whitelist. LLM-only stages remain
    gated. The animation describes major boundaries, not exhaustive stage order.
  - open-pulse-sources library v0.1.2 matches Compose writer image 0.1.2. Library
    reads still share Qdrant/DuckDB. Optional HTTP search/manifest does not imply
    all record hydration is remote. GIMIE is a deployed production dependency.
  - Qdrant retrieval vectors and DuckDB source records have distinct roles;
    embedding models and extraction models have distinct responsibilities.
  - raw.repository maps pulse:watcherCount from _subscribers_count. Existing
    sources/value fallback, web_iri and contract checks are documented exactly.
  - Mapping configuration is packaged, versioned and process-lifetime cached;
    restart is required. Fingerprints identify content but do not archive inputs.
  - Canonical output, optional raw substrate, execution evidence and unifier
    selection provenance in graph:prov are described separately.
  - include_run_report is opt-in and remains a response sibling. Cache-hit reports
    do not invent new execution; usage can be subtotal-only; retrieval is access,
    not derivation; attribution is not factual accuracy or graph coverage.
  - Repository instruction prose still described three schema copies. Actual
    generator reads schema/json/agent and schema/json/strict directly. Promoted
    dev/ontology-v2-json-response directory is absent; tests/v2/fixtures/schema
    contains sample payloads, not duplicate schemas. New maintenance documentation
    follows actual source and does not recreate obsolete copies.

Limits
  Diagrams deliberately summarize complex runtime paths. Actual execution is
  available in the optional run report; enabled paths vary by configuration.
  Wide diagrams scroll on small screens, with prose equivalents for every C4
  view and ordered extraction/update steps when JavaScript is disabled.
  Standalone guide has only local runtime assets. Existing MkDocs theme/search
  dependencies and older Mermaid pages are outside the offline-guide guarantee.
  Full docs deployment is separate; this change does not publish a live page.
