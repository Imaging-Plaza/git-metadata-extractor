  SkipValidation is limited to injected primary clients; data records validate.

  model dumps and repr. API schemas and generated model files are unchanged.

  shorter and describe current behavior.

  and introspection uses class.model_fields. There is no positional shim.
- Dataclasses helpers remain only for third-party data/tool interoperability in
  observation/evidence.py (including Pydantic AI's function_schema).

Compatibility and limits
- Python callers of migrated records must use keyword arguments. Invalid field
  values now raise Pydantic ValidationError; frozen mutation does likewise.
- Pydantic validates/copies input containers. Mutate the resulting model state,
  not an external list/dict that was passed to its constructor.
- model_copy(update=...) is used only for trusted internal transformations; it
  does not validate updates and is not an untrusted-input boundary.
