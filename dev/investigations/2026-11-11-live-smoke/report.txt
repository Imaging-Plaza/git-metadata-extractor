Scope and warnings
The bounded hybrid and LLM profiles run real GitHub context collection and the
repository agent, then the ordinary post-agent sequence; they omit entity
fanout to limit smoke-test cost. They are not full LLM quality benchmarks.
Missing people/org fanout produces orphan-reference warnings and an existing
owner-Person fallback, including an organization account represented as a
Person. SHACL conformance does not establish factual accuracy. Use the full
rule-based output, not the reduced profiles, for meaningful entity counts.

The full rule-based run rejected eight article candidates lacking resolvable
authors. Strict validation also excluded incomplete ROR organization records;
some organization stubs need identifier/UUID normalization. The discipline
tagger still accesses Qdrant/DuckDB directly outside the new remote tool wiring;
full storage decoupling remains incomplete. The first reduced rule-based trial
exposed its old Qdrant hostname; later trials set the correct test-network URL.
