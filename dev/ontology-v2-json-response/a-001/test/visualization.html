Interactive JSON-LD Graph Visualization

  • ⊞ Layouts — Switch between Force Atlas, Circular, Radial, and Grid layouts using the ⊞ button (top-right).
  • 🔍 Search & Filter — Use the sidebar search to find nodes by name. Toggle entity types on/off with the checkboxes.
  • ✓ Validation Badges — Each node shows a green ✓ (pass) or red ✗ (fail) badge for schema validation. Click a node to see full details.
  • ✋ Drag Mode — Enable with the ✋ button, then click and drag nodes to reposition them.
  • 🔗 Table Sync — When enabled (top-left 🔗), clicking a node auto-opens the matching data table tab and highlights the row.
  • 💬 Tooltips — Hover any node or edge for a quick property preview. Toggle with the 💬 button.
  • 📊 Data Tables — Expand the bottom panel to browse all entities by type, or switch to the Validation tab for a full status overview.
