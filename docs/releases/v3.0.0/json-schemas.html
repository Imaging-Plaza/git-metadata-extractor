GME JSON Schemas

Interactive graph viewer for the src/v2/schema/json validation schemas (strict & agent variants)
What this is. The same viewer used in the ontology reference, applied to the project's JSON-Schema entity contracts. Pick a view from the View selector: the Entity overview shows the six entity schemas and the reference properties that link them; each <Entity> · strict/agent view shows that schema's structure — root → properties → nested objects, with type, enum/const, pattern and cross-schema references. Click any node for details.

Schema graph

Colours: dark = root, blue = object, green = array, purple dashed = reference to another schema, amber dashed = enum/const, grey = scalar. Dashed edges are optional properties; solid edges are required.
