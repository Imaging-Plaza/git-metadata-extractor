Open Pulse Ontology

Version v3.0.0 · proposed / draft · models contributions to open-source scientific software and research articles at EPFL
Status: this is a proposed v3.0.0 draft, not a released version. The current production ontology is v2.1.2. This page merges all v2.1.2 terms carried forward, the proposed v3 additions (identity, provenance/observation, publications, organization relationships, cross-platform identifiers), and the internal provider vocabulary. Breaking changes vs. v2: org:unitOf becomes an array, pulse:githubUsername is deprecated, and schema:citation is clarified as a URI.
Internal fields: terms badged GME internal (gme-internal:) are an auxiliary, non-normative vocabulary emitted only when an extract is requested with ?include_internal_fields=true. They are valid RDF but are intentionally not conformant to the closed Open Pulse SHACL shapes.
