# Legacy Releases

This project publishes versioned docs with MkDocs + Mike. The current full docs baseline starts at `v2.0.0`.

## `v1.0.0`

- No maintained `docs/` site structure equivalent to the current versioned documentation.
- Refer to release history in `CHANGELOG.md`.

## `v0.1.0`

- Included minimal documentation artifacts only.
- Refer to release history in `CHANGELOG.md` for historical context.

## Version selector policy

- `dev` and `latest`: docs built from `main`.
- Tagged releases: immutable documentation versions.
- `stable`: alias to the newest released version.
