Public citation excerpts from provider-cache responses retained by the
2026-11-13 sources benchmark (data/benchmarks/sources-20261113).

Each JSON records the source repository, relevant README paragraphs and/or
CITATION.cff / CITATION.bib content. Unrelated auxiliary files, provider
headers, personal provider records and the long ANTs abstract are omitted.
Astropy's CFF excerpt retains its preferred article's identity fields; full
author metadata is intentionally unnecessary for preserving a citation IRI.

Control Toolbox includes the requested BibTeX title and nearby related-paper
links to verify title matching without attributing the whole bibliography.
Lausanne and FCFC retain incidental data/dependency references as negatives.
No network calls are required to exercise these fixtures.
